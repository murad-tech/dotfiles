# ZSH Configurations

This is configuration steps to setup oh-my-zsh

### Make ZSH default

Check which shell are you on by default:
```sh
echo $0

# or

echo $SHELL
```

If your default is not zsh upate it with command:
```sh
chsh -s /bin/zsh
```

Close and reopen Terminal emulator. Then verify.
